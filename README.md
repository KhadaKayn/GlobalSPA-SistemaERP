## 📖 Descripción

**GlobalSPA Sistema ERP** es una aplicación web integral construida sobre Django que permite gestionar los recursos y procesos críticos de la empresa. Incluye módulos de análisis de datos con forecasting predictivo (Prophet), visualizaciones avanzadas y una interfaz de administración personalizada.

## ✨ Características

- ✅ **Gestión ERP completa** — control de recursos, operaciones y flujos empresariales
- 📊 **Análisis predictivo** — forecasting con Prophet, scikit-learn, pandas y numpy
- 📈 **Visualizaciones** — gráficos interactivos con Matplotlib y Seaborn
- 🔌 **API REST** — endpoints con Django REST Framework
- 🎨 **Interfaz moderna** — UI con Bootstrap 5 y django-crispy-forms
- 🛡️ **Panel de administración** — personalizado con django-admin-interface
- 📱 **Diseño responsivo** — adaptado para dispositivos móviles, tablets y escritorio
- 🖼️ **Gestión de imágenes** — soporte de archivos multimedia con Pillow
- 🗄️ **Multi-base de datos** — compatible con MySQL y PostgreSQL

## 🚀 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/KhadaKayn/GlobalSPA-SistemaERP.git
cd GlobalSPA-SistemaERP
```

### 2. Crear y activar un entorno virtual


# Crear entorno virtual
```bash
python -m venv venv
```
# Activar en Windows
```bash
venv\Scripts\activate
```
# Activar en macOS/Linux
```bash
source venv/bin/activate
```

### 3. Instalar dependencias

```bash
pip install -r requirements.txt
```

### 4. Aplicar migraciones

```bash
python manage.py migrate
```

### 5. Acceder al sistema

El sistema viene con un usuario administrador por defecto:

| Campo | Valor |
|---|---|
| **Usuario** | `admin` |
| **Contraseña** | `admin` |

> ⚠️ Se recomienda cambiar estas credenciales en entornos de producción.

### 6. Correr el servidor de desarrollo

```bash
python manage.py runserver
```

La aplicación estará disponible en `http://127.0.0.1:8000/`

<img width="985" height="635" alt="image" src="https://github.com/user-attachments/assets/b775246c-714e-46a4-a216-efe3b1f7cfc0" />

> 🛠️ **Nota para el desarrollador:** Los pasos anteriores corresponden al entorno de desarrollo local. Si el sistema se despliega en un servidor externo (VPS, hosting, nube), el desarrollador a cargo deberá gestionar la configuración del entorno de producción, incluyendo el servidor web (Nginx / Apache), las variables de entorno, la base de datos en producción y las políticas de respaldo y persistencia de datos. La forma en que se almacena, migra y respalda la información dependerá de la infraestructura definida para el proyecto.

## 🗄️ Configuración de Base de Datos

En el archivo `settings.py` dentro del proyecto, configura tu base de datos preferida:

**MySQL:**
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'globalspa_db',
        'USER': 'tu_usuario',
        'PASSWORD': 'tu_contraseña',
        'HOST': 'localhost',
        'PORT': '3306',
    }
}
```

**PostgreSQL:**
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'globalspa_db',
        'USER': 'tu_usuario',
        'PASSWORD': 'tu_contraseña',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```
